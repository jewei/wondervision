# M1 observed verification

Verified on Debian 13 x86_64 with Go 1.27.3 and MyGo v0.7.4. The desktop used
X11 and software rendering; MyGo reported no GPU. Other platforms remain untested.

The source milestone is commit `7fcdb295d42e315bfd1de76fe6c45a1985ec81d6`.
The final link-scope snapshot fix is `b8d8baf`; its build, race tests, and native
workflow were rechecked.

## Gates

- Production build with `mygo_noinspector` and `-trimpath` passed.
- `go test ./...`, `go test -race ./...`, `go vet ./...`, and `go tool mygo vet` passed.
- The real native runner passed from empty preferences, then restarted with its
  persisted profile. Both Open File and Open Folder were driven by toolbar and
  keyboard entry points. The runner used the native GTK dialog's accessibility
  actions to choose exact paths. No internal file-open endpoint was substituted.
- Explorer expansion, dotfiles, standalone opening, GFM/local images, Edit/Preview/
  Split, unsaved preview updates, local links, retained tabs, sidebar toggling,
  quit confirmation, and lazy restore passed. Workspace hashes matched before
  and after edits. Preferences contained only allowed path/UI fields.
- Bounded callback checks passed all 143 schedules. Two scratch variants with
  stale-result guards removed failed behavioral assertions. The original code
  passed again. These are bounded checks, not an unbounded formal proof.

## Artifacts

`native-result.json`, `native-doctor.json`, `native-actions.jsonl`,
`native-filesystem-check.json`, and `native-cleanup.json` are the retained proof
summary, process identity, action trace, disk comparison, and teardown result.
Full actions and accessibility snapshots remain in the local ignored
`build/verification/native-confirmed/` directory. The committed native screenshots
are `docs/screenshots/edit.png`, `preview.png`, and `split.png`.

The four `request-order-*.txt` artifacts record the passing baseline, both
behavioral counterexamples, and the passing unmodified rerun. The reusable
instructions live in `.agents/skills/verify-wondervision/` and
`.agents/skills/verify-request-order/`.

Early native-driver attempts failed around GTK dialog readiness and keyboard
selection. They were treated as failed runs, cleaned up, and replaced with
AT-SPI actions on the real dialog. Only the final passing run is counted here.

## Independent review

An independent GPT-6 Astra read-only review found stale preview authorization on
existing tabs, a rapid-quit preferences gap, and check-then-open symlink races.
The resulting fixes were checked with named behavioral tests and the full native
rerun. This was an independent GPT review; no cross-vendor model was available.
The fixes were validated after the review rather than certified by that reviewer.

## Limits

Save/Save As, tab closing, file mutations, watchers, conflict handling, recovery,
search, Quick Open, palettes, and M4 release hardening remain out of scope.
The 10-minute foreground/minimized and 24-hour performance gates were not run.
No mathematical proof of the entire application is claimed. Bounded tests do not
exhaust mixed UI operations, I/O failures, or framework internals.
